# Chronos Pomodoro 🍅

Link: https://chronos-pomodoro-pied.vercel.app/

Chronos Pomodoro é um aplicativo web para gerenciamento de tarefas e ciclos de
produtividade baseado na Técnica Pomodoro, desenvolvido com React, TypeScript e
Vite.


## ✨ Funcionalidades

- Cronômetro Pomodoro com ciclos de foco, descanso curto e descanso longo
- Personalização dos tempos de cada ciclo nas configurações
- Histórico automático de tarefas, com status de completas ou interrompidas
- Visualização dos ciclos com indicadores coloridos
- Notificações e mensagens para facilitar o uso
- Interface moderna e responsiva

## 🚀 Diferenciais

- Ciclos organizados em sequência, com sugestão automática do próximo ciclo
- Histórico detalhado para acompanhar sua evolução
- Configuração flexível dos tempos de foco e descanso
- Visual intuitivo dos ciclos (foco, descanso curto, descanso longo)

## 📚 Sobre a Técnica Pomodoro

A Técnica Pomodoro consiste em dividir o trabalho em blocos de tempo (Pomodoros)
intercalados com pausas. O objetivo é manter o foco total por um período curto e
garantir descansos para evitar o cansaço mental.

No Chronos Pomodoro, você pode personalizar os tempos e acompanhar seu progresso
de forma automática.

## 📦 Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/chronos-pomodoro.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Rode o projeto em modo desenvolvimento:
   ```bash
   npm run dev
   ```

## 🔧 Configuração

Acesse a página de configurações para ajustar os tempos de foco, descanso curto
e descanso longo conforme sua preferência.

## 🏁 Uso

- Defina o nome da tarefa e inicie o cronômetro
- Acompanhe os ciclos e siga as dicas exibidas
- Veja seu histórico de tarefas e ciclos
- Personalize os tempos conforme sua rotina

## 📊 Histórico

Todas as tarefas e ciclos concluídos ficam salvos no histórico, permitindo
acompanhar sua evolução ao longo do tempo.
